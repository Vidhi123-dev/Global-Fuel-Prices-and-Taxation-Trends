PUBLISH WITH GITHUB PAGES
1. Extract this ZIP on your computer.
2. Open your GitHub repository.
3. Select Add file > Upload files.
4. Upload all files listed above into the repository root (not just the ZIP).
5. Commit the files.
6. Open Settings > Pages.
7. Under Build and deployment, choose Deploy from a branch; branch main; folder /(root); click Save.
8. When the deployment finishes, open the site URL shown in Settings > Pages.

The dashboard shown on the website is a static screenshot. Replace/add a verified published Tableau Public viewer URL after publishing the workbook to Tableau Public. The project report's authoring URL is not assumed to be a public viewer link.
